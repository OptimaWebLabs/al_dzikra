📲 Instal Al-Dzikra di Perangkat Anda

Al-Dzikra adalah Progressive Web App (PWA) yang dapat diinstal secara gratis dan berjalan 100% Offline tanpa kuota internet di semua sistem operasi:

🤖 Android (Chrome / Edge / Samsung Internet)

Ketuk tombol Instal Langsung di atas, atau buka menu titik tiga (⋮) di pojok kanan atas browser lalu pilih "Instal aplikasi" (Install app) atau "Tambahkan ke layar utama".

🍎 iOS & iPadOS (iPhone / iPad via Safari)

1. Buka halaman ini di Safari.
2. Ketuk ikon Bagikan (Share) ⍐ di bilah bawah.
3. Gulir ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen), lalu ketuk Tambah.

🪟 Windows 10 / 11 (Chrome / Microsoft Edge)

Klik ikon Instal Al-Dzikra (⊕ / komputer dengan panah) di sisi kanan bilah alamat (Address Bar), lalu klik Instal. Aplikasi akan muncul di Start Menu & Desktop.

🐧 Linux (Chrome / Chromium / Brave / Firefox PWA)

Di Chrome/Chromium/Brave, klik ikon Install Al-Dzikra di bilah alamat (atau buka menu ⋮ → Save and Share → Install Al-Dzikra...) untuk menambahkan pintasan ke Application Launcher desktop Linux Anda.
