# 🕌 Al-Dzikra — Aplikasi Dzikir Pagi, Petang & Ba'da Sholat

**Al-Dzikra** adalah Progressive Web App (PWA) modern, ringan, dan bebas iklan untuk mengamalkan **Dzikir Pagi (27 bacaan)**, **Dzikir Petang (24 bacaan)**, dan **Dzikir Ba'da Sholat Fardhu (14 bacaan)**.

🌐 **Live Web App (GitHub Pages):**  
👉 **[https://optimaweblabs.github.io/al_dzikra/](https://optimaweblabs.github.io/al_dzikra/)**

---

## ✨ Fitur Utama

- **📖 Tiga Rangkaian Lengkap**:
  - **Dzikir Pagi** (27 bacaan lengkap dengan teks Arab & terjemahan)
  - **Dzikir Petang** (24 bacaan lengkap)
  - **Dzikir Ba'da Sholat** (14 bacaan dengan penyesuaian target otomatis waktu **Subuh**, **Maghrib**, atau **Zuhur/Ashar/Isya**)
- **📿 Penghitung Tasbih Interaktif**:
  - **Mode Daftar (List Mode)**: Lihat seluruh bacaan sekaligus dengan tombol hitung per bacaan dan auto-scroll ke dzikir berikutnya saat target tercapai.
  - **Mode Fokus (Focus Mode)**: Tampilan satu kartu dengan area sentuh tasbih besar (atau tombol `Spasi` / `Enter` di keyboard desktop).
- **🔊 Umpan Balik Getar & Suara Halus**: Haptic feedback dan bunyi klik lembut setiap ketukan serta nada selesai saat target bacaan terpenuhi.
- **🎨 Kustomisasi Nyaman**:
  - Pengaturan ukuran font Arab (`A-` / `Normal` / `A+`)
  - Sembunyikan/tampilkan terjemahan
  - Mode Gelap (**Dark Mode**) & Mode Terang (**Light Mode**)
- **📴 100% Offline-First (PWA)**: Tetap berjalan lancar tanpa koneksi internet setelah dibuka pertama kali.

## 📲 Cara Instal di Berbagai Perangkat

Karena dibangun dengan standar **Progressive Web App (PWA)**, Al-Dzikra dapat diinstal langsung dari browser tanpa melalui toko aplikasi:

1. **🤖 Android (Chrome / Edge / Samsung Internet)**:
   - Buka **[https://optimaweblabs.github.io/al_dzikra/](https://optimaweblabs.github.io/al_dzikra/)**
   - Ketuk tombol **"📲 Instal Aplikasi"** di pojok kanan atas, lalu pilih **Instal**.
2. **🍎 iOS & iPadOS (Safari)**:
   - Buka tautan aplikasi di **Safari**.
   - Ketuk tombol **Bagikan (Share)** di bagian bawah layar, lalu pilih **"Tambah ke Layar Utama" (Add to Home Screen)**.
3. **🪟 Windows 10 & 11 (Chrome / Microsoft Edge)**:
   - Klik tombol **"📲 Instal Aplikasi"** di header atau ikon **Install Al-Dzikra** di bilah alamat (Address Bar). Aplikasi akan terpasang di Start Menu dan Desktop.
4. **🐧 Linux (Chrome / Chromium / Brave)**:
   - Klik tombol **"📲 Instal Aplikasi"** di header atau buka menu **⋮ → Save and Share → Install Al-Dzikra...** untuk menambahkan aplikasi ke Application Launcher Linux Anda.
